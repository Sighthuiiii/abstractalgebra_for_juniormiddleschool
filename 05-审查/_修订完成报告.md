### 2.6 第 14 课新增「环」的完整定义与「一、二、三、四次方程」三页

- **环**：改成明确的**有 \(1\) 的交换环**，逐条写出——①加法满足第 4 课四条且**可交换**；②乘法封闭、结合、**有单位元 \(1\)**、**可交换**，但**不要求每数有逆元**；③**乘法对加法的分配律**（两边都写）。
  并按教师要求**先回指一句分配律**（"你们早就在用了：\(3\times(4+5)=3\times4+3\times5\)"）再入定义；域挂在环上；补一句"乘法可交换，所以又叫交换环"。**三版文字逐字一致。**
- **方程三页**（学生版与教师版同步，课件 3 帧）：按教师要求**先定义中间变量、不全展开**——
  - 二次：设 \(t=x+\frac{b}{2a}\) → \(t^2=\frac{b^2-4ac}{4a^2}\) → 判别式与求根公式；
  - 三次（卡尔达诺）：设 \(t=u+v,\ uv=-\frac p3\) → 归结为 \(z^2+qz-\frac{p^3}{27}=0\)；
  - 四次（费拉里）：引入中间变量 \(y\) 配方 → 归结为关于 \(y\) 的三次方程 → 拆成两个二次方程。
  每页一句"一句话"总结，并说明"全写出来能占满一整块黑板"，为"五次没有公式"作铺垫。**没有任何全展开的求根公式。**

## 6. 修订过程中发生的一处事故（留档）

插图环节中，有一个执行者用 PowerShell 的 `(Get-Content -Raw) -replace ... | Set-Content -Encoding UTF8` 做文本往返，
把 `02-课件\第02课-从余数到模运算\第02课-从余数到模运算.tex` 的**中文整份双重编码**（UTF-8 当 GBK 读再以 UTF-8 写回），文件报废且**不可逆**。

处理：从 git 恢复该文件，再重新施加插图替换，并**按损坏副本的残余内容重建**了另一执行者在此文件上的 2 处改动
（新增「本课目标」帧、把 `block` 换成 `definition[同余]`）。

**审查者独立复核**：该文件当前**无 U+FFFD、无 mojibake 特征**；`git diff` 显示改动恰为"新增本课目标帧 + 同余定义 + 3 处 `\imgfig`"，
与预期一致；帧数 21、页数 46，与"帧 + `\pause` = 页"关系吻合 ✅。

**教训（已写进工作约定）**：本工作区的中文 `.tex` 文件**不要**用 PowerShell 做文本读写往返，一律用 `read`/`edit` 工具。
