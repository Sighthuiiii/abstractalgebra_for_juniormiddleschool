厦门大学附属实验中学 · 校本课程 · 授课教师：**姜博瀚**

## 三、怎么编译

编译器：**XeLaTeX**（本机路径 `C:\texlive\2022\bin\win32\xelatex.exe`）。

### 课件（beamer）—— 编译两遍

在课件所在文件夹里运行：

```
xelatex -interaction=nonstopmode 第NN课-主题.tex
xelatex -interaction=nonstopmode 第NN课-主题.tex
```

第二遍是为了顶部导航栏的节名与小圆点（记录在 `.nav` 文件里）。

主文件开头固定是这两行：

```latex
\documentclass[10pt]{beamer}
\input{../../00-共享/preamble.tex}
```

### 讲义（两本册子）—— 编译两遍

在 `03-讲义` 目录下运行：

```
xelatex -interaction=nonstopmode 讲义-教师版.tex
xelatex -interaction=nonstopmode 讲义-教师版.tex

xelatex -interaction=nonstopmode 讲义-学生版.tex
xelatex -interaction=nonstopmode 讲义-学生版.tex
```

第二遍是为了目录。**注意：去 `03-讲义` 目录里运行，不要在子文件夹里运行。**

### 新建一课怎么做

1. **课件**：把 `00-共享\template.tex` 复制到 `02-课件\第NN课-主题\`，改名为 `第NN课-主题.tex`，
   改主文件里的 `\title` / `\subtitle` / `\author` / `\institute` / `\date`，然后编译两遍。
2. **讲义**：在 `03-讲义\教师版\` 和 `03-讲义\学生版\` 里各建一个 `第NN课-主题.tex`，
   开头分别写 `\jhlesson{课次}{课题}{本课信息}` 和 `\xhlesson{课次}{课题}{本课信息}`，
   然后写正文。
3. **主文件不用动**：`讲义-教师版.tex` / `讲义-学生版.tex` 里已经列好了 14 课，
   文件还不存在的那几课会自动跳过，编译日志里留一行提示。写好一课就自动出现在册子里。

## 四、课件的 4 个方框（`00-共享\preamble.tex`）

改配色、字体、校徽栏、页脚，**只改这一个文件**。

| 想改什么 | 搜索关键词 |
| --- | --- |
| 五类方框的颜色 | `boxThm` `boxDef` `boxExm` `boxPrf` `boxNote` |
| 主色（导航栏、页脚、强调色） | `maingreen` `accentgreen` `textgreen` `darkgreen` `lightgreen` |
| 顶部校徽栏高度、校徽大小 | `logo bar`；`ht=0.84cm` 是栏高，`height=0.72cm` 是校徽高 |
| 页脚右侧姓名 | 用的是 `\insertauthor`，即主文件的 `\author` |

**方框写法**（都支持补充名，显示成「标题（补充名）」）：

- 定理类（深绿）：`theorem` / `corollary` / `character` / `proposition` / `lemma`
- 定义类（海绿）：`definition` / `axiom`
- 例题类（森林绿）：`example` / `exercise` / `homework`
- 过程类（橄榄绿）：`proof` / `jie` / `way1`~`way4`
- 注记类（青绿）：`experience` / `zhu` / `att` / `analyse` / `hint`
- beamer 自带：`\begin{block}{标题} ... \end{block}`

**图片**：`\imgph{说明}` 或 `\imgph[高度]{说明}` 是占位框。
有图之后换成 `\includegraphics[width=0.7\textwidth]{图片名}` 即可；
图片放在课件文件夹下的 `图片\` 子目录，或直接和 `.tex` 放同一层。

**动画**：用 `\pause`。一个 `\pause` 会把这一页拆成两页，
用途是「先问，停住，等学生想，再给答案」。

## 五、讲义（两本册子）

### 教师版：务实，少加框

只保留 **4 个方框**：

| 方框 | 用途 | 颜色 |
| --- | --- | --- |
| `mubiao` | 本课目标（每课开头） | 蓝 |
| `definition` | 定义 | 蓝 |
| `example` | 例 | 青绿 |
| `xiaojie` | 本课小结（每课结尾） | 深绿 |

其余一律排成**普通段落、不加框**：`caozuo` 讲台操作 / `zhu` 注 / `jielun` 结论。
写法照旧是 `\begin{caozuo} ... \end{caozuo}`，只是渲染出来没有框、没有底色。

### 学生版：留足空白，能写能画

| 方框 | 用途 | 颜色 |
| --- | --- | --- |
| `mubiao` | 本课目标 | 蓝 |
| `definition` | 定义 | 蓝 |
| `example` | 例 | 青绿 |
| `sikao` | 想一想（开放问题，**框内自带书写线**） | 橙 |
| `dongshou` | 动手做 | 紫 |
| `xiaojie` | 我学到了什么 | 绿 |

留白命令：`\liukong{行数}`，例如 `\liukong{4}` 画 4 道横线。
它整块不可拆分，不会被排到两页上去。**行数必须写在大括号里。**
（`sikao` 和 `dongshou` 两个框本身也不可拆分，所以问题和书写线一定在同一页。）

### 印刷提示

- 两本册子都是 **A4 单面排版**，直接双面打印、装订即可。
- 封面与目录**不编页码**，正文从第 1 页开始，目录里的页码和正文对得上。
- 学生版的书写线是浅灰，**黑白打印也看得见**；彩色打印效果更好。
- 如果要印成 A5 对折的小册子（骑马钉），告诉我，我加一个双页拼版的版本。

## 六、课堂约定（写在所有课里）

- **50 人演示型**：不分小组、不下地、不围坐；教具只有三角形纸片与正方形纸片，都在老师手上。
- **纸片**：正面写顶点，**背面涂另一种颜色**，翻折时后排才看得清。
- **节奏**：0—6 回顾 / 6—28 演示 / 28—40 跟做 / 40—45 收尾，**最后 5 分钟永不挤占**。
- **唯一的参与抓手**：每课至少 4 次「用手指回答」——老师报问题，全班同时举手指作答。
- **术语控制**：全课程新术语 ≤ 20 个，教室墙设「术语账本」。
- **首尾呼应**：第 1 课把 `999999 ÷ 7` 写在黑板最右边、整学期不擦；第 13 课当场划掉。

## 七、踩过的坑（改文件前扫一眼）

- **课件顶部导航栏不更新**：编译两遍。
- **讲义多出空白页**：封面、目录、正文之间**连续两次分页**就会多一张空白页。
  主文件里那几行故意不留空行，不要随手加。
- **`\liukong{4}` 里的数字被打到纸面上**：说明参数写成了可选参数，改成必选（`[1]` 不是 `[1][]`）。
- **`\z@` 报错**：普通 `.tex` 文件里 `@` 不是字母，写 `0pt` 代替。
- **`Option clash for package xcolor`**：`\PassOptionsToPackage{dvipsnames,svgnames}{xcolor}` 要写在
  `\usepackage{graphicx,tikz}` **之前**。
- **找不到 `logo_white.png`**：确认主文件用的是 `\input{../../00-共享/preamble.tex}`，`../..` 不能少。
